# Ginger-Runner

A browser game. Work in progress.

## Structure

- `index.html`: the game page
- `css/`: styles
- `js/`: game logic
- `assets/images/characters/`: character sprites
- `assets/images/equipment/`: equipment and item sprites
- `assets/images/backgrounds/`: backgrounds and scenery
- `assets/images/ui/`: buttons, icons, and HUD art
- `assets/audio/`: sound effects and music

## Run locally

Open `index.html` in a browser.
